# Gábio Bank - GBTP

Implementação do protocolo Gabio Bank Transaction Protocol (GBTP).

## Arquitetura
Este repositório contém a implementação do Cliente Web (Frontend).
- **Ana:** HTML/CSS e Interface Inicial
- **Wesley:** Módulo de Parsing do GBTP (`src/protocol.ts`) e Documentação
- **Nilson:** Conexão WebSocket e Integração (`src/main.ts`)

## Executando o Cliente
Para instalar as dependências e iniciar o servidor do cliente:
```bash
cd gabio-client
npm install
npm run build
npm start
```
